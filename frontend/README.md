# Frontend Angular

Este directorio contiene el frontend Angular para WebRomaPedidos / RomaDB.

## Ejecutar

1. Instala dependencias:
   ```bash
   cd frontend
   npm install
   ```
2. Inicia el servidor de desarrollo:
   ```bash
   npm start
   ```

## Backend esperado

El frontend consume el backend Spring Boot en `http://localhost:8080/api`.
